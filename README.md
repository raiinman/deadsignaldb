# Dead Signal DB

Dead Signal DB is an independent creative practice and public home for software, games, tools, systems, and experiments made to explore ideas and help people.

The site is not a conventional portfolio and is not tied to one technology or medium. It is a living index of work: what is active, what has shipped, what is being explored, and what has been archived.

## Current projects

- [Wakeframe](https://wakeframe.deadsignaldb.com/) — autonomous research system.
- [Once Human](https://oncehuman.deadsignaldb.com/) — evidence-driven database and build-planning project.

## Product concept

The public homepage is **The Signal Field**: an interactive field where projects appear as distinct signals. Exploration is atmospheric, but every interaction has a clear accessible index fallback.

## Repository scope

This repository contains the Dead Signal DB parent brand and portal. Individual projects remain in their own repositories and may use entirely different technologies.
